# 📝 答题句式总则

> 句库是「以高考真题答案为基础、以教材原文为依据」的答题语言资产。先记骨架，再填真题金句，考场上按链作答。

## 一、得分动词表（阅卷先看动词）

| 动词 | 含义 | 常用搭配 |
|------|------|----------|
| 描述 | 说清"是什么" | 分布/特征/变化 |
| 说明 | 解释"为什么" | 原因/条件/机制 |
| 分析 | 拆解因果链 | 成因/影响/利弊 |
| 评价 | 权衡正负面 | 意义/影响/合理性 |
| 论证 | 给出证据链 | 依据/推理/结论 |
| 比较 | 辨异同 | 差异/优劣/变化 |
| 归纳 | 提炼规律 | 特征/趋势 |
| 推测 | 预判演化 | 趋势/后果 |

## 二、五大句式骨架（对应评分细则思维模型）

1. **特征—成因—影响链**：先描述现象，再解释成因，最后说影响。
2. **时空逻辑链**：按"何时—何地—何过程"递推，避免时空混杂（对应 E-05）。
3. **三维结构（经济/社会/生态）**：综合题从三维度展开，防结构缺失（对应 E-04）。
4. **收支平衡模型**：水量、热量、物质"收入—支出"对比，用于水文/环境题。
5. **措施—目标—约束**：开放题先给动作，再指目标，兼顾约束条件。

## 四·补 图表判读方法论
> 来源：「图表类型及解读方法」通用读图套路。通用读图防错套路，适用于所有题目卡读图环节（OCR 抓不到图，故以文字方法入库）。

- **雷达图**：数据为相对量（比重/比例）；距原点越远占比越大，各轴数值之和 = 100%。
- **风玫瑰图**：同心多边形大小 = 频率；辐射线段 = 方向；交点读各风向频率，比出最大/最小风频（风向判读题必用）。
- **地理原理/过程示意图**：看箭头方向、线段纵横关系提取因果链；判各因素时空变化规律（综合题"说明过程"题核心）。
- **地理关联示意图**：先定主体、找突破口，按箭头先后填框，再回验逻辑（框图填空防错位）。
- **区域经纬网图**：定范围 → 推热量带 → 结合海陆/经度推气候与农业 → 依相对位置推经济结构/外贸条件/地质资源。
- **区域专题地图**：从繁杂信息中**提取单一要素、排除干扰因素迷惑**（审题关键：先揭分布形态 → 析成因 → 对准问题指向）。
- **剖面图**：地形剖面看地势起伏；地质剖面判构造/岩性/矿产；河流—地下水剖面看河床成因、沉积物、潜水承压水与互补关系；锋面/台风剖面判势力关系、雨区、天气变化。
- **表格**：抓主线要素（体现命题意图）；定性 + 定量结合；横向类比异同相似点。
