# M-02 区位因素分析（工业）

## 一句话定义
- 用“传统六要素（原料/能源/市场/劳动力/交通/政策）+ 现代要素（科技·信息·环境·集聚）”双维框架，先**判定导向型**，再解释工业（或工业园区、产业链）为何布局在某地，并能写出“优势—限制—升级方向”。

## 核心机制（因果链）
- 工业选址本质：在满足生产条件下，使**成本最低 / 效率最高 / 风险可控 / 收益最大**。
- 原料、能源、交通决定“生产能不能低成本运转”；市场、产业配套、技术决定“能不能卖得快、做得高端”。
- 政策、环境与土地决定“能不能落地、能不能持续”；集聚效应决定“能不能协同降本、知识溢出”。
- 产业升级：由资源 / 低成本驱动 → 向技术 / 品牌 / 服务化驱动转型（附加价值沿产业链上移）。

## 答题要点清单

### 1. 双维要素框架（必背，按湘教版教材分组）
- **传统区位因素**：原料、能源（动力）、市场、劳动力、交通、政策。
- **现代区位因素**：科技（信息）、环境、集聚效应。
- 答题时按“自然类（原料/能源/水/地形土地）+ 社会经济类（交通/市场/劳动力/技术/政策/配套）”分组列点，避免漏类。

### 2. 五大导向型决策表（答题第一步·定性质）
| 导向型 | 核心特征 | 典型产业 | 布局指向 |
|--------|----------|----------|----------|
| 原料导向型 | 原料运输成本＞产品，或原料易腐、减重明显 | 制糖、水产加工、水果罐头、钢铁（近铁近煤） | 靠近原料地 |
| 市场导向型 | 产品不便运输 / 易腐 / 增重 / 时效强 | 啤酒、家具、印刷、食品饮料、瓶装饮料 | 靠近市场 |
| 动力导向型 | 高耗能，能源成本占比大 | 电解铝、有色金属冶炼、电镀 | 靠近能源基地 / 电力充足区 |
| 劳动力导向型 | 需大量普通劳动力，工资敏感 | 服装、电子装配、制鞋、玩具 | 劳动力丰富且成本较低处 |
| 技术导向型 | 技术 / 人才密集，研发依赖强 | 集成电路、精密仪表、生物制药、软件、人工智能 | 高校科研区 / 高新技术园区 |

> 口诀：**“原料重、市场近、耗能找电、人多打工、技高进园”**。

### 3. 工业区位变化规律（答“变化题”必用）
- **减弱**：原料、动力、数量型劳动力的影响在下降（交通改善 +  globalization + 自动化）。
- **增强**：市场、交通、知识技术、信息、政策、环境（环保约束）的影响在上升。
- 布局演变总趋势：原料 / 动力导向 → 市场 / 交通导向 → 科技 / 信息导向（临空型、临港型、高新区）。

### 4. 环境导向布局分级（高频硬考点）
- **按污染程度分级**：
  - 无污染 / 轻污染（电子、服装、食品）→ 可布局城区或近郊；
  - 轻度污染 → 城市边缘；
  - 重污染（钢铁、化工、造纸、印染、火电）→ **远郊、远离居民区与水源地**。
- **风向选址**：盛行风下风向 / 最小风频上风向 / 与季风垂直方向的郊外。
- **河流选址**：水污染企业布局在河流**下游**、远离水源保护区与取水口。
- **环境要求高的产业**（电子、精密仪器、自来水厂）→ 布局在环境洁净、上风向、上游。

### 5. 集聚 vs 分散权衡
- **集聚**：共享基础设施、降低协作与物流成本、形成规模效应与品牌、知识溢出（见 M-13 产业链 + 产业集群模板）。
- **分散**：为寻求最优区位、规避地价上涨 / 污染集中 / 接近目标市场而分散布局（总部—生产分离、核心—配套分离）。

### 6. 三步成文（写得又快又全，含分值映射）
1. **定性质（1 分基础）**：该产业为 __ 导向型（据第 2 表判定）。
2. **写优势（每点 2 分，选 4–5 点写满）**：自然类 2 点（原料 / 能源 / 水 / 地形土地）+ 社会类 3 点（交通 / 市场 / 配套 / 技术 / 政策）。
3. **写限制与优化（1–2 条闭环）**：环保 / 水 / 地价 / 劳动力短板 + 对应升级措施（清洁生产、循环经济、智能化、研发品牌、延链补链）。

### 7. 高分表达词库（可直接套，呼应句库 S-06）
- “靠近原料地，降低运输成本”“临港临铁、物流便捷、辐射范围广”。
- “产业基础雄厚、配套完善（上下游集聚、协作降本）”。
- “人才与科研优势明显、创新能力强、创新平台集聚”。
- “政策扶持力度大、园区平台完善、用地指标保障”。
- “环保约束趋严，需清洁生产与循环利用、达标排放”。
- “集聚带来规模效应、知识溢出与品牌效应”（见 M-13）。

## 常见图表与判读
- **风玫瑰图（F-07 盛行风 + 污染扩散 + 选址）**：判主导风向与最小风频 → 解释重污染企业“下风向 / 最小风频上风向 / 垂直郊外”布局。
- **交通干线 / 枢纽分布图（F-32 中国地形与政区图·交通干线）**：港口 / 铁路 / 高速 / 机场 → 解释“物流成本低、辐射范围大、临港临路布局”。
- **三次产业结构图（统计图表直接判读，库内暂无独立图表卡）**：二产比重高 → 工业基础雄厚；三产上升 → 服务化与研发支撑。
- **土地利用 / 遥感影像（园区扩张判读）**：园区临港临路、连片扩张 → 指向交通与产业集聚优势（判读参考 F-32 交通干线）。
- **一句话读图模板**：“该地位于 __ 交通枢纽 / 通道，便于原料输入与产品外运；周边 __ 市场 / 产业配套完善，并有 __ 政策与人才支撑，因此形成 __ 工业集聚。”

## 高频题型与答题框架（4 条）
- **题型1：解释某工厂 / 园区选址（最常见）**
  - 定向：__ 导向型（用第 2 表）。
  - 优势：原料 / 能源 / 交通 / 市场 / 劳动力 / 技术 / 政策（选 4–5 点写）。
  - 限制 + 措施：环保 / 水 / 地价 / 拥堵等（写 1–2 条闭环）。
- **题型2：比较两地工业区位差异（对比题）**
  - 同要素对比：A 靠港 → 外向型强；B 靠资源 → 资源型明显。
  - 再补：A 人才与技术强 → 高端；B 劳动力成本低 → 加工装配。
- **题型3：产业转移 / 升级分析**
  - 转出地原因：成本上升（地价 / 劳力 / 环保）→ 外迁。
  - 承接地优势：交通改善 + 政策园区 + 劳力 / 土地成本低。
  - 升级方向：高端制造、智能化、绿色低碳、研发与品牌、服务化（生产性服务业）。
- **题型4：工业上楼 / 多层标准厂房（2024–2025 新课标卷热点）**
  - 判据：**生产类型与特征决定楼层选择**。
  - 适“上楼”：设备轻、占地小、无污染（软件、研发、精密制造、电子信息）→ 高容积率多层厂房。
  - 不适“上楼”：设备重、占地大、有污染（机械装备制造、化工）→ 低层大跨度厂房。
  - 官方评析印证：机械装备制造业设备重、占地大不适合高层，软件产业主要设备为电脑网络最适合“上楼”（见 S-06 教育部考试院评析）。

## 易错点与纠偏
- **易错1：只写“交通便利、政策支持”两句万能话**
  - 纠偏：必须补“产业导向”与“关键要素”（原料 / 能源 / 市场 / 技术至少 1 条具体落地）。
- **易错2：把所有工业都写成“靠近市场”**
  - 纠偏：先判导向型（原料 / 能源 / 劳动力 / 技术 / 市场），不同产业核心不同。
- **易错3：忽视环保与用水**
  - 纠偏：重化工 / 造纸 / 印染等必须写“水源 + 环保约束 + 治理措施”，并按污染等级与风向 / 河流布局。
- **易错4：升级写得空泛**
  - 纠偏：写成“设备更新 + 清洁生产 + 循环经济 + 延链补链 + 研发品牌”至少 2 条。
- **易错5：环境布局不分污染等级 / 不写风向河流**
  - 纠偏：重污染远郊 + 下风向 / 最小风频上风向 + 河流下游；洁净产业反之（上风向 / 上游）。


### 大招
**大招17 材料分析法搞定工业区位因素**——给出的可操作步骤：
- **第一步：寻找材料里的答题线索**。圈出交通线（铁路/港口）、相邻城市、资源禀赋、政策表述等关键词。
- **第二步：结合材料按维度组织答案**。高频维度三类：
  - **交通便利性**：有铁路/水运线经过 → 便于要素流通；
  - **经济环境**：靠近某城市群/产业集聚区 → 产业协同便利；
  - **相邻位置**：距产业转出地适中 → 便于承接转移。
- **真题印证（2025 安徽卷·湘潭新能源汽车链式承接）**：靠近长沙处长株潭、距东部沿海适中、有铁路连通——三个维度各 2 分。
> 与本条模板「导向型判定→要素分组→环境分级」互为表里：材料分析法解决"从材料到要点"，导向型解决"从要点到性质"。
