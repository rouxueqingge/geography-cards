# M-17 区域特征描述模板（位置→自然→人文 逐项成链）

## 一句话定义
- 对任意尺度区域（大洲/国家/分区），按"位置→自然地理特征→人文地理特征"的固定维度逐项描述，形成结构化、不漏点的区域特征画像，是区域认知素养的底层模板。

## 核心机制（因果链）
- 区域特征 = 位置（经纬度/海陆/相对）决定气候与水热条件 → 气候+地形决定水文/植被/土壤 → 自然基底叠加社会经济决定人口/城市/农业/工业/交通。
- 描述顺序即因果顺序：先定位（因），再特征（果），避免跳跃与漏项。

## 答题要点清单
1. **位置（四要素，缺一不可）**：半球位置 + 经纬度位置（温度带/纬度带）+ 海陆位置（临海/内陆/大洲部位）+ 相对位置（相邻区域/交通要道）。
2. **自然特征五维**：地形地势（类型/地势/地形区）→ 气候（类型/气温/降水/季节）→ 水文水系（补给/汛期/流量/航运）→ 植被土壤 → 自然资源。
3. **人文特征四块**：人口城市（分布/密度）→ 农业（地域类型/作物/熟制）→ 工业（部门/分布/基地）→ 交通（干线/枢纽）。
4. **尺度切换**：大洲看"分区共性+典型差异"；国家看"主导区位+特色产业"；分区看"主导限制因子被突破的机制"（如绿洲/河谷）。

## 常见图表与判读
- **区域图（F-31）**：先定位（经纬网/轮廓/海陆）再提取自然人文特征。
- **中国地形与政区图（F-32）**：提取三级阶梯、地形区、交通干线。
- **气候分布图**：据纬度+海陆判定气候类型与分布。

## 高频题型与答题框架
- **题型1：描述某区域自然地理特征** → 位置+地形+气候+水文+植被土壤，逐项一句。
- **题型2：说明区域特征成因** → 用 M-04 成因机制，沿"位置→地形→气候"链条推导。
- **题型3：评价区域发展的条件** → 自然+人文"有利/不利"双栏，再给措施。

## 易错点与纠偏
- 易错1：只写经纬度漏海陆/相对位置 → 纠偏：位置四要素并列写全。
- 易错2：自然与人文混写、漏项 → 纠偏：严格按"自然五维+人文四块"清单打勾。
- 易错3：把"位置"与"经纬度位置"等同 → 纠偏：位置是四要素集合，经纬度只是其一。


### 大招
**思维6 整体→局部特征类**：
- **先整体后局部**：描述分布时先说"整体是否均匀/总体趋势"，再点"哪里多哪里少、哪里高哪里低"。
- **气候特征顺序**：先描述气温（整体及局部变化），再描述降水（整体及局部变化）；气温与降水均遵循"整体→局部"思路。
- 与本条模板「位置→自然→人文」互补：思维6 解决"特征描述的内部逻辑顺序"，位置→自然→人文解决"特征描述的维度框架"。
