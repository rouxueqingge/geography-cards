# M-18 区域比较答题模板（多尺度 / 南北方 / 四大分区）

## 一句话定义
- 在 M-07 比较类基础上，专为"区域"场景定制的对比模板：按统一维度对两个（或多个）区域并列对照，重点解释差异的**区域成因**（纬度/海陆/地形/洋流/人文）。

## 核心机制（因果链）
- 区域差异根源 = 位置差异（纬度/海陆）→ 水热组合差异 → 自然特征差异 → 人文活动差异。
- 比较的"原因"必须回到区域属性（尺度、区位），而非泛泛"自然条件不同"。

## 答题要点清单
1. **先同后异**：开头写1条共同点（同温度带/同沿海/同流域），再列差异。
2. **统一维度并列**：每个维度用"A…；B…"对称句（≥3组），维度优先选：位置/地形/气候/水文/农业/工业/城市。
3. **南北方专用维度**：地形（平原为主 vs 低山丘陵）、气候（温带季风 vs 亚热/热带季风）、农业（旱作 vs 水田；小麦 vs 水稻）、资源（煤铁石油 vs 有色金属）、界线（秦岭—淮河多重意义）。
4. **四大分区专用维度**：北方（旱作/春旱/煤铁）、南方（水田/红壤/洪涝）、西北（干旱/绿洲/荒漠化）、青藏（高寒/河谷/三江源）。
5. **解释差异原因**：对每处"异"给1–2条区域成因（纬度/海陆/地形/洋流/人类活动）。

## 常见图表与判读
- **区域对比图（F-31/F-32）**：提取两区位置与特征逐项对照。
- **气候统计图（F-05/F-14）**：对比气温年较差、降水季节分配。
- **地形图（F-10/F-32）**：对比地势、地形区、坡度。

## 高频题型与答题框架
- **题型1：比较南北方自然与人文差异** → 按"地形/气候/农业/资源"四维度并列+秦岭—淮河意义。
- **题型2：比较两大洲气候差异并解释** → 同（都受__影响）；异（A年较差大，B温暖湿润）；因（地形走向/海陆/洋流）。
- **题型3：比较四大分区生态问题** → 北方盐碱水土、南方红漠化石漠化、西北荒漠化、青藏湿地退化，各自因果链。

## 易错点与纠偏
- 易错1：写成"分别描述"无对照 → 纠偏：必须 A…；B… 成对。
- 易错2：只写差异不写原因 → 纠偏：每条差异配区域成因。
- 易错3：南北方漏"秦岭—淮河多重意义" → 纠偏：既是界线也是1月0℃/800mm/水田旱作/亚暖温带界。
