# Q-120 滦河三角洲潟湖—沙坝海岸与曹妃甸围海造陆（2024浙江卷6月·28题·20分）

## 【基本信息】
- **年份卷别**：2024 年浙江省高考地理（6 月选考）第 28 题
- **分值**：20 分（4+3+7+6）
- **主题**：海岸地貌（潟湖—沙坝）、围海造陆对生态环境的影响、岸线生态修复效果评估
- **核心素养**：区域认知、综合思维、人地协调观

## 【命题立意】
以滦河三角洲潟湖—沙坝海岸及曹妃甸围海造陆工程为情境，考查地貌形成过程、人类活动对海岸环境的影响、生态修复评价指标，体现海洋空间资源安全与人地协调。

## 【情境材料】
材料一：滦河三角洲潟湖—沙坝海岸是由滨岸沙坝与其内侧的潟湖和陆域海岸组成，曹妃甸岛原为该海岸滨岸沙坝中的沙岛。2003 年对曹妃甸岛以北的浅海滩涂（潟湖）实施围海造陆工程，在带来巨大社会和经济效益的同时，也对周边海区潮流等环境产生影响，改变了自然岸线形态特征，挤占了生态空间。近年来部分岸线实施了生态修复项目，取得了良好的效果。
材料二：图 1 为曹妃甸围海造陆工程范围示意图。图 2 为岸线（海堤和岸滩）生态修复项目设计示意图。

## 【问题】
1. 图中带状沙岛的分布走向是__________，并简析其形成过程。（4 分）
2. 围海造陆工程实施后，甲海域表层沉积物的粒径变粗，解释其形成原因。（3 分）
3. 分析围海造陆工程对潟湖生态环境的不利影响。（7 分）
4. 列举评估岸线生态修复效果的主要指标。（6 分）

## 【解析】
- **第 1 问**：走向东北—西南（平行于海岸线）；形成 = 河流泥沙入海 + 潮流/沿岸流推动堆积成沙坝 + 部分露出海面成岛。
- **第 2 问**：围海使岸线平直化 → 水动力增强 → 细颗粒被冲刷分选带走 → 粗颗粒沉积。
- **第 3 问**：围海占用 → 潟湖萎缩、纳潮量减少、水体交换减弱、水质下降、生物多样性与生态功能退化。
- **第 4 问**：从岸线修复（长度、湿地面积、形态、沉积物）与环境生境（物种多样性、水质、植被、潮汐幅度等）两维度列举。

## 【参考答案】
1. **走向**：东北—西南走向（平行于海岸线）。**形成过程**：河流携带大量泥沙在入海口附近沉积；受潮流推动、沿岸流影响，泥沙平行于海岸堆积形成滨岸沙坝；随时间推移沙坝不断增高，部分露出海面形成带状沙岛。
2. 围海造陆后，甲海域附近水动力变强；细颗粒物不易沉积，不断被冲刷分选、被带走，粗颗粒物更易沉积，故表层沉积物粒径变粗。
3. 围海占用潟湖水域，潟湖面积减小；潮流减弱、淤积增加，潟湖萎缩；潟湖内纳潮量减少，与海洋水体交换能力减弱，水质下降；生物多样性减弱，生态功能退化。
4. **岸线修复**：修复海岸线长度、滨海湿地面积、岸线形态（地形）、沉积物类型及分布。**环境及生境**：物种多样性、滨海湿地水质、湿地植被面积（种类）、湿地生物种类（密度）、植物成活率、植被覆盖率、潮汐幅度、外来物种数量和种类。

## 【考场增值】
- **地貌过程链**：物源（河流泥沙）→ 动力（潮流/沿岸流）→ 堆积（沙坝）→ 出露（沙岛），不可颠倒次序。
- **人类活动影响答题**：占用空间 → 动力改变 → 水文连通性下降 → 水质/生态退化，层层递进。
