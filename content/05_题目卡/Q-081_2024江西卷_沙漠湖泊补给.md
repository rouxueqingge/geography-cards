# Q-081 2024江西卷·沙漠湖泊补给

## 基本信息
- **来源**：2024年江西省普通高中学业水平选择性考试 第19题
- **题型**：综合题（3问，21分）
- **对应知识卡**：[[../02_知识卡/02_01_自然地理/K-04_地球上的水.md]] · [[../02_知识卡/02_01_自然地理/K-09_陆地水与洋流.md]]

---

## 【命题立意】
以沙漠高大沙山与湖泊的水量平衡争议为学术情境，考查降水下渗补给估算、假设合理性质疑、以及用多指标验证补给来源的科学探究链条。**核心素养**：综合思维（水量收支建模）+ 地理实践力（设计监测指标验证猜想）+ 人地协调观（水资源约束下的湖泊维持）。

## 【情境】
沙漠内沙山约20000km²、湖泊约20km²；年均降水约70mm、湖面蒸发约2000mm。小组一据"一次降水>15mm部分补给地下水"假设，算得降水补给（1.6×10⁸m³）>蒸发（4×10⁷m³），认为降水足以维持湖泊。小组二质疑该假设，猜测湖泊主要补给来自深层大断裂带的区外地下水。

## 【问题】
1. 计算"沙山区地下水—湖泊"系统的降水年补给量与湖泊年蒸发量（以m³计），给出过程与结果。（7分）
2. 列出2条反对"一次降水超过15mm部分都补给地下水"假设的理由。（8分）
3. 为验证猜测，选水温、水位、水化学成分中任意2个指标，分别说明选择依据。（6分）

## 【解析】

### (1) 水量平衡计算
| 项目 | 计算 |
|------|------|
| 沙山区降水补给地下水 | 8/1000 × (20000×1000²) = 1.6×10⁸ m³ |
| 湖泊降水补给 | 70/1000 × (20×1000²) = 1.4×10⁶ m³ |
| 系统降水总补给 | 1.6×10⁸ + 1.4×10⁶ = 1.614×10⁸ m³ |
| 湖泊年蒸发量 | (2000/1000) × (20×1000²) = 4×10⁷ m³ |

**落点**：补给（1.614×10⁸）> 蒸发（4×10⁷），小组一结论成立；须写清计算过程。

### (2) 假设质疑（反对理由）
| 理由 | 要点 |
|------|------|
| 下渗后仍有蒸发 | 降水下渗至0.3m以下（或之前）仍会蒸发，忽略则高估补给 |
| 地表径流损失 | 部分降水未下渗、地表成径流最终耗于蒸发，未补给地下水 |
| 侧向渗出 | 下渗过程中可能以径流/泉水渗出地表耗于蒸发 |

**落点**：任何"忽略蒸发/径流损失→高估补给"的逻辑均可，须写过程而非只给结论。

### (3) 验证指标依据
| 指标 | 选择依据 |
|------|----------|
| 水温 | 深层断裂带地下水水温较高且稳定→湖水温季节变化小、年均明显高于气温（冬季偏稳） |
| 水位 | 深层地下水受当地降水影响小→湖水位季节变化小且与降水无显著相关 |
| 水化学成分 | 深层水含较高背景矿物（锶/硒/锂/锌/偏硅酸）且含量稳定 |

**落点**：任选2个，指标现象须与"深层断裂带来源"逻辑自洽。

## 【参考答案】
(1) 沙山区地下水降水补给量：8/1000×(20000×1000²)=1.6×10⁸m³；湖泊降水补给量：70/1000×(20×1000²)=1.4×10⁶m³；系统降水总补给=1.614×10⁸m³；湖泊年蒸发量=(2000/1000)×(20×1000²)=4×10⁷m³。
(2) ①该部分降水下渗至0.3m以下（或之前/过程中）仍有蒸发，忽略会增大补给估算；②该部分降水可能未下渗、在地表形成径流最终耗于蒸发，忽略会增大补给估算（或下渗中侧向渗出地表耗于蒸发）。
(3) 水温：深层断裂带地下水水温较高且稳定，若湖水温季节变化小、年均明显高于气温则印证；水位：深层地下水受当地降水影响小，若湖水位季节变化小且与降水无显著相关则印证；水化学成分：深层水含较高背景矿物（锶/硒/锂/锌/偏硅酸）且含量稳定则印证。（任选2）

## 【考场增值】
- **规律印证**：06过程推演（水量收支建模）+ 09链条设问（假设—质疑—验证的科学链）。
- **易错警示**：① 计算题不写过程、只用文字表达（官方答题反馈原话，对应 [[../06_错因纠偏卡/E-08_机制表层化型错误|E-08]]）；② 第(2)问只给结论不写"忽略XX会高估补给"的因果；③ 第(3)问指标现象须与"深层断裂带来源"对应，忌套模板（见 [[../06_错因纠偏卡/E-07_图表信息提取偏差型错误|E-07]]）。
- **答题模板**：水量平衡 = 收入(降水/区外补给) − 支出(蒸发/径流)；质疑假设 = 找被忽略的损失项。
