# F-05 气温-降水组合图判读（气候类型快速判定）

## 一句话定义
- 将**气温年变化曲线**与**降水年内分配柱状**叠加，按"以温定带、以水定型"快速判定**气候类型**及其成因。

## 核心机制（因果链）
- 气温定带：最冷月均温→温度带（热带>15℃ / 亚热带>0℃ / 温带<0℃ / 寒带全年低）。
- 降水定型：降水总量+季节分配（年雨型/夏雨型/冬雨型/少雨型）→ 大气环流与下垫面。
- 组合判定：温+水组合→气候类型→典型植被/农业熟制/自然带。

## 答题要点清单
- **三步走必写**
  1. **以温定带**：最冷月均温 → 热带/亚热带/温带/寒带（写出临界值）。
  2. **以水定型**：看降水柱状分配 → 夏雨/冬雨/年雨/少雨。
  3. **组合命名**：如"夏雨型+最冷月>0℃→亚热带季风气候"。
- **高分关键词库**
  - 热带：终年高温、年雨/夏雨、雨林/草原/季风/沙漠。
  - 亚热带：最冷月>0℃、夏雨（季风）/冬雨（地中海）。
  - 温带：最冷月<0℃、夏雨（季风/大陆性）/年雨（海洋性）。
  - 寒带：全年低温、少雨。
- **常用对照句**
  - "最冷月均温>15℃为热带；0–15℃为亚热带；<0℃为温带，再据降水季节定具体类型。"

## 常见图表与判读
- **图像抓手**
  - 峰在7月+最冷月>0℃+夏雨多 → 亚热带季风。
  - 全年均匀+最冷月>0℃ → 温带海洋性。
  - 夏雨集中+最冷月<0℃ → 温带季风/温带大陆性。
  - 冬雨（冬半多）+夏干 → 地中海气候。
- **一句话模板**
  - "以温定带（最冷月__℃→__带），以水定型（__雨型），组合判定为__气候。"

## 高频题型与答题框架
- **气候类型判定题**：先温后水，两步落名，补成因（气压带风带/海陆/地形/洋流）。
- **分布与特征题**：据类型答分布规律+气温降水特征+自然带。

## 易错点与纠偏
- 易错1：只写"降水多"不判类型。  
  - 纠偏：必须"温+水"两步组合命名。
- 易错2：亚热带季风与温带海洋性混淆。  
  - 纠偏：看最冷月（>0 亚热带 / 全年温和海洋性）+ 降水季节。
