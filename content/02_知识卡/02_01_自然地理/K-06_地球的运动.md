# K-06 地球的运动（选必·深化）

## 课标定位
- **教材**：选择性必修1 第一章《地球的运动》（湘教版选必1）
- **两节**：1.1 地球的自转；1.2 地球的公转
- **课标要求**：结合实例，说明地球运动的地理意义（自转→昼夜交替·时差·地转偏向力；公转→正午太阳高度·昼夜长短·四季五带）

## 知识结构
```
地球的运动
├── 1.1 自转
│   ├── 特征：自西向东；恒星日23h56m4s / 太阳日24h
│   ├── 速度：角速度≈15°/h（极点除外均相同）；线速度 v=1670·cosφ km/h（赤道最大→两极0）
│   └── 地理意义：昼夜交替(晨昏线)·地方时/区时·地转偏向力(北右南左)·国际日界线
└── 1.2 公转
    ├── 特征：轨道近圆(1月初近日点/7月初远日点)；恒星年365d6h9m；角速度≈1°/d；线速度≈30km/s
    ├── 黄赤交角 23°26′ → 太阳直射点回归运动（南北回归线之间）
    └── 地理意义：正午太阳高度变化·昼夜长短变化·四季更替·五带划分
```

## 核心原理（因果链）
1. **线速度纬度差异**：v=1670·cosφ → 赤道最大、向两极递减；海拔升高线速度略增（低纬发射场优势）。
2. **地转偏向力**：自转→水平运动物体北半球向右、南半球向左偏转（洋流/河流/气流偏移→凹凸岸、港口选址）。
3. **时差链**：经度每隔15°→地方时差1h，东早西晚；区时=中央经线地方时；180°附近国际日界线东侧减一天。
4. **黄赤交角→直射点回归**：23°26′交角决定回归线23°26′、极圈66°34′。
5. **正午太阳高度**：H=90°−|φ−δ|；夏至北回归线以北最大、冬至最小；南北回归线之间一年两次直射。
6. **昼夜长短**：太阳直射哪一半球，该半球昼长夜短；赤道全年平分；极圈内出现极昼/极夜。

## 教学重难点
- ⚠️ **晨昏线判读**：与太阳光线垂直、平分地球；晨线≈6时、昏线≈18时；确定昼夜半球与日出日落时刻。
- ⚠️ **地转偏向力方向**判定及对应地理事象（侵蚀岸/沉积岸、三角洲偏移、向右偏转的气流漩涡）。
- ⚠️ **正午太阳高度公式** H=90°−|φ−δ| 代入与极值（φ 与 δ 同减异加）。
- ⚠️ **昼夜长短的纬度/季节分布**与极昼极夜范围（直射点移动方向决定昼长变化趋势）。
- ⚠️ **四季与五带划分依据**：正午太阳高度+昼夜长短的季节变化→热量差异。

### 大招3 秒懂新旧日期
- **180° 经线为界**：判断日界线两侧日期，新的一天自 180° 经线向东递减。
- **找地方时 0 时经线**：从而确定新旧日期的范围；若 180° 经线地方时为 N 时，则新的一天占全球 N/24。

### 考点整合（核心）
- **自转**：方向自西向东（北逆南顺）；周期 恒星日23ʰ56ᵐ4ˢ（真正周期）/太阳日24ʰ；速度 角速度除极点均≈15°/h，线速度 1670×cosα km/h（向两极递减，海拔越高越大）。
- **自转意义**：昼夜交替、地方时（东加西减）、地转偏向（北右南左）、晨昏线判读（晨线：赤道6时/昼半球西侧；昏线：赤道18时/夜半球东侧）。
- **公转**：轨道近正圆、1月初近日点最快/7月初远日点最慢；黄赤交角23°26′→太阳直射点回归运动。
- **公转意义**：正午太阳高度、昼夜长短（直射点所在半球昼长夜短且昼渐长）、四季与五带。
- **计算**：昼长＝2×(日落－12)＝24－夜长；南北半球同纬度昼夜长短"对称"；二至日对称两日期昼夜状况相同。

### 高分考法（高分思路）
- 时间/日期计算：经度÷15°定时区（余数>7.5进1）；东加西减；行程问题"起点时间＋飞行时长"再处理日界线。
- 昼夜长短变化：先定直射点位置与移动方向→判半球昼夜长短与变化趋势。

### 典型考例（书中引用）
- 多配"某日光照图/日出日落时刻"计算；公转意义常结合同一纬度昼夜对称规律。
