# K-02 地球表面形态

## 课标定位
- **教材**：湘教版必修第一册 第二章（p40-68）
- **课时**：3节（流水地貌 → 风成地貌 → 喀斯特、海岸和冰川地貌）
- **课标要求**：通过野外观察或运用视频、图像，识别3~4种地貌，描述其特点

## 知识结构
```
地球表面形态
├── 2.1 流水地貌
│   ├── 侵蚀：V形谷·峡谷·河漫滩·河流阶地·曲流与牛轭湖
│   ├── 堆积：冲积扇·洪积扇·冲积平原·三角洲·江心洲
│   └── 灾害：滑坡·泥石流
├── 2.2 风成地貌
│   ├── 风蚀：风蚀蘑菇·风蚀壁龛·风蚀柱·雅丹地貌
│   ├── 风积：新月形沙丘·灌丛沙丘
│   └── 防治：草方格·石方格·防护林
└── 2.3 喀斯特、海岸和冰川地貌
    ├── 喀斯特：溶沟·石芽·峰林·孤峰·溶斗·天坑·钙华
    ├── 海岸：海蚀崖·海蚀平台·海蚀柱·海滩·沙嘴·离岸堤
    └── 冰川：冰斗·U形谷·角峰·刃脊·峡湾
```

## 核心原理（因果链）
1. **流水地貌形成**：流速变化（坡度/水量）→ 侵蚀（下切/侧蚀）或 堆积（出山口/中下游/河口）→ 对应地貌
2. **风成地貌形成**：干旱区 + 大风 + 沙源 → 风蚀（吹蚀/磨蚀）或 风积（风速降低 → 沉降）
3. **喀斯特形成**：石灰岩 + 水 + CO₂ → 溶蚀作用 → 地表（峰林/溶斗）+ 地下（溶洞/石钟乳）
4. **灾害链**：暴雨 + 陡坡 + 破碎岩体 → 滑坡/泥石流 → 堵江·掩埋·伤亡

## 教学重难点
- ⚠️ **冲积扇 vs 洪积扇 vs 三角洲** 地理位置和形态区别
- ⚠️ **曲流→牛轭湖**的演化过程（裁弯取直的触发条件）
- ⚠️ **喀斯特地貌**的"溶蚀/沉积"双重性
- ⚠️ **滑坡 vs 泥石流**的触发条件和物质组成差异

### 考点整合（核心）
- **经纬网/地图**：经纬线特征；经纬度实质（纬度＝线面角，经度＝面面角）；地图三要素（方向/比例尺/图例）；比例尺缩放（图幅＝原×(缩放倍数)²）。
- **等高线**：五大地形类型（平原<200m/丘陵/山地>500m/高原/盆地）；判读口诀 凸低为脊、凸高为谷、重叠为崖；相对高度与陡崖高差计算；应用（选点/选线/选面）。
- **岩石圈循环**：三大类岩石（岩浆岩：花岗岩侵入/玄武岩喷出；沉积岩：层理+化石；变质岩：大理岩/板岩）；岩浆是循环的"起点与归宿"。
- **内力作用**：地壳运动（褶皱—背斜山/向斜谷，但"地形倒置"：背斜成谷、向斜成山）；板块边界（生长—裂谷海洋；消亡—褶皱山/海沟/岛弧）；地质过程表述：断裂→岩浆侵入→抬升→风化侵蚀露出。
- **外力作用**：风化/侵蚀/搬运/堆积；流水（V形谷/喀斯特/千沟万壑）、风力（雅丹/沙丘）、冰川（U形谷/角峰）、海浪（海蚀崖/海蚀平台）；影响因素 气候（干湿）、岩性、地势。

### 高分考法（高分思路）
- 内力地貌成因过程题：按"地壳运动→岩浆活动→抬升→外力侵蚀"链条表述（如花岗岩球状风化、玄武岩山体）。
- 外力地貌类型判断：先定气候带（干旱—风力/湿润—流水/高山高纬—冰川/滨海—海浪），再看发育阶段。

### 易错易混
- 背斜≠山、向斜≠谷（地形倒置）；潜水与承压水、向斜与背斜的含水差异。

### 典型考例（书中引用）
- 等高线常配"局部等高线判读河流流向"；内外力常配"地貌形成过程"描述题。

### 补充对接：考点3 地理信息技术（3S）
- **考点整合**：GIS 处理空间数据（叠加分析）→ 灾害范围确定、减灾预案、损失评估；RS 对地物感知（范围大/速度快/周期短/信息量大）→ 灾害形成过程监测与预警、快速识别影响范围；GNSS 定位导航（全球/全天候/连续/实时）→ 求救定位、缩短救援搜寻时间。
- **700分口诀**："想看（面上信息获取）找 RS，想算（分析决策）找 GIS，想定位（点）找 GNSS"。
- **易错**：GNSS 只能定位导航，不能监测水文数据、不能直接探测水深。
- **典型考例**：［河北2025·14］卫星遥感图像可识别河流形态特征（不能算输沙量/径流量）；北斗夜航主要用于校正航向。
