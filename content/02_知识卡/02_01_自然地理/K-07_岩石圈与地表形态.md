# K-07 岩石圈与地表形态（选必·深化）

## 课标定位
- **教材**：选择性必修1 第二章《岩石圈与地表形态》（湘教版选必1）
- **两节**：2.1 岩石圈物质循环；2.2 地表形态的变化
- **课标要求**：运用示意图，说明岩石圈物质循环过程；结合实例，解释内力与外力对地表形态的影响

## 知识结构
```
岩石圈与地表形态
├── 2.1 岩石圈物质循环
│   ├── 三大类岩石：岩浆岩(侵入/喷出)·沉积岩(层理·化石)·变质岩
│   └── 循环：岩浆→岩浆岩→沉积岩/变质岩→重熔再生（软流层为源）
└── 2.2 地表形态的变化
    ├── 内力：板块构造(六板块·生长/消亡边界)·地质构造(褶皱:背斜/向斜;断层:地垒/地堑)
    └── 外力：风化→侵蚀→搬运→沉积→固结成岩（流水·风力·冰川·海浪）
```

## 核心原理（因果链）
1. **物质循环**：岩浆活动→岩浆岩；外力风化侵蚀→碎屑物沉积→沉积岩；高温高压→变质岩；重熔→回归岩浆（规模大、历时最长）。
2. **板块边界**：消亡边界（碰撞）→山脉/海沟/岛弧；生长边界（张裂）→裂谷/大洋中脊。
3. **地质构造**：背斜岩层上拱（顶部受张力易侵蚀成谷）、向斜岩层下弯（槽部受挤压耐蚀成山）→"地形倒置"。
4. **断层组合**：地垒（相对上升→块状山/陡崖）、地堑（相对下降→谷地/盆地）。
5. **外力分异**：流水（下切→峡谷、侧蚀→曲流、沉积→冲积扇/三角洲）；风力（风蚀→雅丹、风积→沙丘）；冰川（冰蚀→U谷/角峰、冰碛→丘陵）。

## 教学重难点
- ⚠️ **三大类岩石判别**：有无层理/化石（沉积岩）、有无气孔/流纹（喷出岩）、有无片理（变质岩）。
- ⚠️ **岩石圈物质循环图**的箭头方向（岩浆只生岩浆岩；变质作用双向）。
- ⚠️ **背斜向斜"地形倒置"**：不看地形看岩层新老定构造。
- ⚠️ **内外力叠加**：同一地貌常由内力抬升+外力塑造共同完成（如华山地垒+流水下切）。

### 答题建模要点
- 过程推演「**因→过程→果**」框图 + 五步：找起点（构造 / 气候 / 人类干预）→ 拆环节 → 找反常 → 连因果 → 达终点。

- 地貌发育模板库（侵蚀 / 沉积 / 构造 / 灾害链）每日 1 框图。



### 大招10 四角度判岩层新老
- 确定 → 岩层新老关系 → 接触关系 → 理论判断。
- **层序律**：沉积岩下老上新；侵入者新、被切断者老、喷出晚于基底。
- 注意上述判断须参照同一个海岭或海沟；接触关系（整合/不整合）常是推理题眼。
- 真题印证（2025 浙江卷1月·某地地质剖面图，根据地层接触关系与化石定岩层新老顺序）
