# K-22 区域地理·世界地理总览索引

> 本卡为「世界地理」板块的**总览索引卡**。逐考点细卡已拆分：K-24 世界地理概况 / K-25 亚洲 / K-26 美洲 / K-27 其他大洲。本卡只做框架收束与导航，具体知识整合与考法见各细卡。

## 课标定位
- **教材衔接**：初中世界地理 → 湘教版必修1（自然地理基础）/ 选必2（区域认知延伸）
- **课标要求**：运用地图等资料，描述世界典型区域的地理位置、自然与人文地理特征；通过区域比较归纳区域差异，形成"位置→自然→人文"的区域认知链条。

## 核心原理（因果链）
1. **区域特征分析链**：位置（纬度/海陆）→ 地形 → 气候 → 水文/植被/土壤 → 人文（农业/工业/城市）。
2. **地形对气候的制约**：北美中部平原贯通（气流长驱直入、大陆性强）vs 南美安第斯紧逼西岸（气候狭长）vs 欧洲平原+北大西洋暖流（海洋性广）。
3. **大洲分界线**：亚欧（乌拉尔—乌拉尔河—里海—高加索—黑海—土耳其海峡）、亚非（苏伊士）、亚北美（白令）、南北美（巴拿马）、德雷克、直布罗陀。

## 教学重难点
- ⚠️ 地形对气候的影响（北美 vs 南美对比）是高考高频。
- ⚠️ 科考站纬度：我国长城站在南极圈外（唯一），中山/昆仑/泰山/秦岭在圈内，北极黄河站在圈内。

> 依据一轮考点体系高分考法（考法62/65/68）与 ima 知识库「11大规律」整合。

### 命题规律定位
- 主规律：**08 区域比较** · **07 综合贯通**

### 代表性真题例证
- 全国乙 2022·36 以色列海水淡化（临海+天然气+城市供水）。

### 答题建模要点
- **大洲特征描述模板**：位置 → 地形 → 气候 → 河湖 → 资源 → 人口·城市·农业·工业，逐项成链。
- **"地形对气候影响"题**：山脉走向 → 阻挡/通道 → 气候分布形态（狭长带/长驱直入）。
