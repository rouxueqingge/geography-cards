# 📚 知识卡（课标主题模块）

> **定位**：湘教版课标主题的综合知识卡片——层级高于概念卡，每个主题覆盖一个完整的教学单元或核心知识模块。

---

## 与概念卡的关系

```
知识卡（课标主题层）
  └── 概念卡（原子术语层）
       └── 概念辨析卡（易混对比层）
```

- **知识卡**：回答"这个主题讲了什么"→ 覆盖范围、知识结构、核心原理、课标要求
- **概念卡**（07_）：回答"这个概念是什么"→ 定义、机制、答题要点
- **概念辨析卡**（10_）：回答"这两个概念怎么区分"→ 对比、判据

**示例**：
- 知识卡「大气受热过程」↔ 概念卡「太阳辐射」「地面辐射」「大气逆辐射」「温室效应」
- 知识卡「水循环」↔ 概念卡「蒸发」「降水」「径流」「下渗」「水循环」

## 编写规范

每张知识卡遵循统一结构：
1. **课标定位** — 对应湘教版章节 + 课标要求
2. **知识结构** — 核心概念关系图（文字描述或 Mermaid）
3. **核心原理** — 2-3条关键因果链
4. **教学重难点** — 学生常见卡点
5. **关联卡片** — 链接到下属的概念卡、图表卡、方法卡
