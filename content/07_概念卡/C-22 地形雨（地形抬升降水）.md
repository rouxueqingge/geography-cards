# C-22 地形雨（地形抬升降水）

## 一句话定义
- 地形雨是湿润气流遇山地被迫抬升、冷却凝结形成的降水，常发生在**迎风坡**，背风坡易少雨。

## 核心机制（因果链）
- 盛行风/季风携带水汽 → 遇山抬升 → 冷却凝结 → 降水增多
- 水汽在迎风坡被消耗 → 越岭后下沉增温 → 雨影效应 → 背风少雨

## 答题要点清单
- 关键词：迎风坡、山脉阻挡、抬升、雨影、背风干旱
- 条件：稳定水汽输送 + 明显地形抬升
- 影响：迎风坡湿润、河流发育；背风坡干旱、荒漠化风险（按题干）

## 常见图表与判读
- 剖面图：迎风坡云雨多→地形雨典型
- 一句话模板：  
  - “水汽随__风到达山地→迎风坡抬升冷却凝结→形成地形雨。”

## 高频题型与答题框架（2–3条）
- 成因题：水汽来向+抬升机制→迎风多雨、背风少雨（对比写）
- 雪线题：迎风坡降水多→积雪多→雪线相对较低（同山体）

## 易错点与纠偏
- 易错：不写水汽来向直接判迎风
  - 纠偏：先定盛行风/季风方向，再判迎风坡
