# C-08 季风

## 一句话定义
- 季风是在同一地区，风向随季节发生显著转换、并伴随降水季节性变化的盛行风现象。

## 核心机制（因果链）
- 海陆热力差异 → 冬夏气压形势反转 → 风向季节转换
- 夏季：海洋→陆地输送水汽 → 上升凝结 → 雨季形成
- 冬季：陆地→海洋干冷气流 → 下沉增温/水汽少 → 旱季形成
- 季风强弱变化 → 直接影响降水丰枯与旱涝灾害

## 答题要点清单
- 关键词：冬夏风向相反、雨季旱季、雨热同期、季风强弱
- 常见影响：夏季洪涝、冬春干旱；对农业熟制与水资源配置影响大
- 得分表达：水汽输送、雨热同期、季节性显著、旱涝不均

## 常见图表与判读
- 风玫瑰/风向资料：冬夏主导风向明显相反 → 季风特征
- 一句话模板：  
  - “冬季__风、夏季__风，风向季节反转并致降水季节性强→受季风控制。”

## 高频题型与答题框架（2–3条）
- 成因：海陆热力差异+气压形势季节变化→风向反转→雨旱季
- 影响：季风偏强/偏弱→降水偏多/偏少→洪涝/干旱

## 易错点与纠偏
- 易错：把盛行风都当季风  
  - 纠偏：季风必须体现“风向季节反转”，否则多为风带或局地风
