# C-18 外流河

## 一句话定义
- 外流河是河水最终汇入海洋（或经湖泊再入海）的河流类型，常见于湿润半湿润区，径流相对更充沛稳定。

## 核心机制（因果链）
- 降水相对较多 → 径流形成充足 → 河网发育
- 地势由内陆向海洋倾斜 → 水系向海汇集 → 入海口形成河口地貌
- 人类修坝/取水/拦沙 → 改变下游水量水沙与河口演变（常见）

## 答题要点清单
- 关键词：入海、河网密、径流量大、三角洲/河口
- 表述加分：上中下游分异明显（上游侵蚀，中下游堆积为主的一般规律）
- 得分词：入海通道、河口地貌、径流稳定性较高（相对内流河）

## 常见图表与判读
- 河口/三角洲分布图：河流入海形成沉积地貌
- 一句话模板：  
  - “降水较多、径流稳定且最终入海→判为外流河。”

## 高频题型与答题框架（2–3条）
- 判类型：是否入海+流域干湿状况→结论→2条依据
- 河口变化：来水/来沙变化→三角洲淤积或萎缩（按题干）

## 易错点与纠偏
- 易错：把“外流河=一定水量大”绝对化  
  - 纠偏：水量受降水、流域面积、取水工程影响；外流仅说明“终入海”
