# C-33 喀斯特地貌（岩溶地貌）

## 一句话定义
- 喀斯特地貌是可溶性岩石（以石灰岩为主）在流水溶蚀作用下形成的地表与地下综合地貌，如溶洞、石林、峰林、天坑等。

## 核心机制（因果链）
- 含CO₂的水 → 形成弱酸性 → 溶解碳酸盐岩
- 裂隙与节理发育 → 水沿裂隙渗入 → 溶蚀扩大 → 地下洞穴形成
- 地表水易下渗 → 地表径流少 → 干旱缺水与石漠化风险（按题干）
- 地下河发育 → 溶洞塌陷 → 漏斗/天坑等地貌

## 答题要点清单
- 关键词：石灰岩、溶蚀、溶洞、地下河、峰林、漏斗、天坑
- 环境特征：地表水少、下渗强；土层薄、生态脆弱（石漠化）
- 规范表达：溶蚀作用、裂隙渗流、地下径流发育

## 常见图表与判读
- 地貌照片/剖面：溶洞、地下河、峰林峰丛→喀斯特
- 一句话模板：  
  - “石灰岩分布+裂隙发育，含CO₂水溶蚀→地下洞穴与峰林等喀斯特地貌形成。”

## 高频题型与答题框架（2–3条）
- 成因题：岩性（可溶）+水化学（含CO₂）+裂隙→溶蚀→地貌
- 问题与治理：石漠化/缺水→封育恢复+保土蓄水+合理用水（见M-06）

## 易错点与纠偏
- 易错：只写“流水侵蚀”  
  - 纠偏：喀斯特关键是“**溶蚀**”，不是机械侵蚀
