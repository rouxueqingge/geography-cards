# 📖 概念卡（原子术语层）

> **定位**：单个地理术语的精细化解析——每一张卡回答"这个概念是什么、机制如何、怎么考、易错在哪"。

---

## 两层分工（2026-07-26 确认）

```
知识卡（02_）→ 课标主题模块（如「大气受热过程」「水循环」）
  └── 概念卡（07_）→ 原子术语解析（如「太阳辐射」「蒸发」「径流」）★ 本目录
       └── 概念辨析卡（10_）→ 易混概念对比（如「风化 vs 侵蚀」）
```

## 编写规范

每张概念卡统一六段：
1. **一句话定义** — 最精炼的定义
2. **核心机制（因果链）** — 成因→过程→结果
3. **答题要点清单** — 关键词 + 判据
4. **常见图表与判读** — 题干抓手 + 读图模板
5. **高频题型与答题框架** — 2-3种典型考法
6. **易错点与纠偏** — 错在哪 + 怎么改

## 当前统计

- C-01 ~ C-52：52张，覆盖自然地理核心术语
- 包含：风化、侵蚀、气候类型、地形地貌、水文、大气、生态等
