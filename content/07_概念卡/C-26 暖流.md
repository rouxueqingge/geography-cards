# C-26 暖流

## 一句话定义
- 暖流是从低纬流向高纬、或流经海域水温高于同纬度海水的洋流，常使沿岸**增温增湿**。

## 核心机制（因果链）
- 风带推动 + 地转偏向力 + 海陆轮廓约束 → 形成大洋环流
- 暖流输送热量 → 提升沿岸气温 → 蒸发加强 → 水汽增多
- 水汽条件改善 → 沿岸降水/雾霾变化（按题干）→ 影响农业、渔业与港口结冰情况

## 答题要点清单
- 关键词：增温、增湿、降水可能增多、港口不易结冰
- 常见效应：冬季增温明显；利于海上航运与沿岸湿润气候
- 规范表达：热量输送、蒸发增强、水汽条件改善

## 常见图表与判读
- 世界洋流图：西岸多寒流、东岸多暖流（一般规律，结合题图）
- 一句话模板：  
  - “受__暖流影响，沿岸热量与水汽输送增强→气温升高、空气更湿润。”

## 高频题型与答题框架（2–3条）
- 气候影响题：暖流→增温→蒸发→水汽→（湿润/降水）
- 港口结冰题：暖流增温→海水不易结冰→利于冬季航运

## 易错点与纠偏
- 易错：把“暖流=一定降水多”绝对化  
  - 纠偏：降水还取决于大气环流与抬升条件；暖流主要稳定表述为“增温增湿”
