# C-49 酸雨

## 一句话定义
- 酸雨是pH值低于5.6的降水（雨、雪、雾等），主要由SO₂、NOx等污染物在大气中转化为硫酸/硝酸后溶于水形成。

## 核心机制（因果链）
- 燃煤/工业/交通排放SO₂、NOx → 大气氧化反应 → 生成硫酸、硝酸
- 与水汽结合/溶于云滴 → 随降水沉降 → 酸雨形成
- 影响：土壤与水体酸化、建筑腐蚀、植被受损（按题干）

## 答题要点清单
- 关键词：SO₂、NOx、硫酸硝酸、沉降、酸化
- 空间特征：排放源下风向更易发生（结合盛行风写）
- 防治：脱硫脱硝、清洁能源、机动车尾气治理、区域联防联控

## 常见图表与判读
- 题干：燃煤+下风向降水酸度高→酸雨
- 一句话模板：  
  - “SO₂/NOx排放→大气转化为硫酸/硝酸→溶入降水→形成酸雨，并在下风向更明显。”

## 高频题型与答题框架（2–3条）
- 成因题：排放—转化—沉降（3段链条）
- 措施题：源头（能源结构）+过程（脱硫脱硝）+管理（标准监管）

## 易错点与纠偏
- 易错：把酸雨成因写成“CO₂过多”  
  - 纠偏：酸雨核心污染物是SO₂、NOx，不是CO₂
