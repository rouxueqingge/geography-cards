# C-03 堆积

## 一句话定义
- 堆积是搬运物在动力减弱时**沉降累积**的过程，常形成冲积扇、三角洲、沙洲等地貌。

## 核心机制（因果链）
- 载体动力减弱（流速变小/坡度变缓/入海入湖） → 搬运能力下降
- 颗粒按粒径分选沉降（粗先细后） → 地表抬高 → 堆积地貌形成

## 答题要点清单
- 关键词：沉积、淤积、堆积、河口/湖口、出山口、三角洲
- 条件：来沙充足 + 动力明显减弱
- 典型地貌：冲积扇（出山口）、三角洲（河口）、河漫滩（中下游）

## 常见图表与判读
- 看到“出山口、河口、坡度变缓”→优先判堆积
- 一句话模板：  
  - “因__（坡缓/流速减小）→搬运力下降→泥沙沉积→形成__。”

## 高频题型与答题框架（2–3条）
- 地貌判定：位置+动力变化+沉积物粒径分选→结论
- 工程影响：修坝拦沙→下游来沙减少→河口三角洲萎缩（按题干）

## 易错点与纠偏
- 易错：忽略“来沙条件”  
  - 纠偏：动力弱只是必要条件，来沙不足则堆积不明显
