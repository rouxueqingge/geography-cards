# C-38 逆温（大气稳定层结）

## 一句话定义
- 逆温是指在某一高度范围内，气温随高度升高**反而升高**（或降低变慢），使大气层结更稳定、对流受抑的现象。

## 核心机制（因果链）
- 夜间地面辐射冷却/冷空气堆积 → 近地面降温更快 → 上暖下冷形成逆温 → 垂直对流被抑制 → 水汽/污染物不易扩散 → 易出现雾、霾、空气质量恶化。

## 关键判据与特征
- 层结判据：温度廓线出现“向上升温”的段落（逆温层）。
- 时空判据：多见于**晴朗少风夜间—清晨**；盆地/谷地易冷空气堆积。
- 影响判据：能见度下降、雾霾加重；逆温破坏（加热/风增强/降水）后好转。

## 常见图表与判读
- 温度垂直廓线：出现逆温层→稳定层结→扩散差。
- 句式模板：
  - “夜间辐射冷却导致近地面强降温，形成逆温层，抑制对流与扩散，使污染物在近地面累积。”

## 高频设问与答题要点
- **为什么雾霾重？**：逆温+静风+地形（盆地）+排放（按题干）四选三。
- **何时易出现？**：秋冬清晨、晴朗少云少风、地形封闭区。
- **如何改善？**：气象（大风/降水/日照升温破坏逆温）+人为（减排）。

## 易错点与纠偏
- 易错：只写“排放大”解释雾霾。  
  - 纠偏：高分必须补“扩散条件差（逆温/静风/地形）”。
