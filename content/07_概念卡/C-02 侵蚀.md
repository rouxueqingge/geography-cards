# C-02 侵蚀

## 一句话定义
- 侵蚀是外力（流水、风、冰川、海浪等）对地表的**破坏与搬运**过程，结果是地表被削低、物质被带走。

## 核心机制（因果链）
- 动力（流速/风力/冰川运动）增强 → 冲刷/磨蚀 → 物质被剥离
- 物质被搬运 → 地表降低、沟谷加深/坡面变陡
- 与堆积联动：动力强处侵蚀，动力弱处堆积 → 共同塑造地貌

## 答题要点清单
- 关键词：冲刷、下切、搬走、削坡、沟谷加深、海蚀、风蚀
- 影响：塑造峡谷、冲沟、海蚀崖；增加含沙量；诱发水土流失
- 强弱条件：坡陡/流速大/降水集中/植被差→侵蚀强

## 常见图表与判读
- 等高线密集+暴雨集中→汇流快→侵蚀强
- 一句话模板：  
  - “因__（坡陡流急/暴雨集中/植被稀少）→侵蚀增强→__（沟谷加深/水土流失）。”

## 高频题型与答题框架（2–3条）
- 水土流失成因：降水强度+坡度+植被+人类扰动→侵蚀增强→含沙量↑
- 河流地貌：上游下切/中下游侧蚀与堆积（按河段写）

## 易错点与纠偏
- 易错：只写“降水多”  
  - 纠偏：侵蚀还看“坡度、下渗、植被、汇流速度”
