# C-32 河漫滩

## 一句话定义
- 河漫滩是河流中下游在洪水期漫溢淤积、枯水期出露的滩地，是河流侧蚀与堆积共同作用形成的平坦地貌单元。

## 核心机制（因果链）
- 洪水期水位上涨 → 河水漫出河槽 → 流速骤减 → 细颗粒泥沙沉积
- 枯水期水位下降 → 滩地出露 → 形成河漫滩
- 凹岸侵蚀、凸岸堆积 → 河槽摆动 → 河漫滩不断更新（按题干）

## 答题要点清单
- 关键词：洪水漫溢、细泥沉积、枯水出露、平坦、肥沃
- 典型特征：地势低平、土壤肥沃，适宜农业但洪涝风险高
- 得分词：漫溢沉积、洪泛平原的一部分（按题干）

## 常见图表与判读
- 河谷平原图：河道两侧低平带状滩地→河漫滩
- 一句话模板：  
  - “洪水期漫溢→流速减小细泥沉积→枯水期出露→形成河漫滩。”

## 高频题型与答题框架（2–3条）
- 地貌判读：中下游+两侧低平带状+洪水淤积→河漫滩
- 影响与治理：利于耕作但易洪涝→行洪区管控、堤防与预警（见M-06）

## 易错点与纠偏
- 易错：把河漫滩当成“三角洲”  
  - 纠偏：河漫滩在河道两侧；三角洲在河口入海入湖处
