# C-25 平流雾（海雾/平流冷却雾）

## 一句话定义
- 平流雾是暖湿空气水平移动到较冷的下垫面上，被冷却至露点后凝结形成的雾，沿海常见为海雾。

## 核心机制（因果链）
- 暖湿气流平流（水平移动） → 经过冷海面/冷地面
- 自下而上被冷却 → 达到露点 → 凝结成雾
- 盛行风持续输送 + 冷下垫面维持 → 雾易持续、范围较大

## 答题要点清单
- 关键词：沿海、海雾、暖湿气流、冷海面/寒流、持续性、范围大
- 条件：暖湿空气+冷下垫面+一定风（能输送但不宜过大）
- 影响：港航受阻、能见度降低、沿海交通影响大

## 常见图表与判读
- 题干提“寒流流经海域、海雾频发”→平流雾高概率
- 一句话模板：  
  - “暖湿气流移至冷下垫面（如寒流海域）→被冷却至露点→形成平流雾。”

## 高频题型与答题框架（2–3条）
- 成因题：水汽（暖湿）+冷却方式（平流冷却）→雾
- 区域题：寒流沿岸/春夏之交→海雾多（按题干）

## 易错点与纠偏
- 易错：把平流雾写成“夜间辐射冷却形成”
  - 纠偏：平流雾核心是“**暖湿气流移动到冷面**”，不是夜间地面辐射
