# C-27 寒流

## 一句话定义
- 寒流是从高纬流向低纬、或流经海域水温低于同纬度海水的洋流，常使沿岸**降温减湿**，并易形成海雾（在特定条件下）。

## 核心机制（因果链）
- 风带推动 + 地转偏向力 + 海陆轮廓约束 → 形成环流分支
- 寒流降低近海气温 → 蒸发减弱 → 水汽减少 → 沿岸偏干
- 暖湿气流经过冷海面 → 被冷却至露点 → 平流雾（海雾）易发
- 寒流常伴上升流 → 营养盐上涌 → 渔场形成（若题干涉及）

## 答题要点清单
- 关键词：降温、减湿、沿岸干旱、海雾、渔场
- 常见效应：西岸沿海常更干凉；春夏海雾多（按题干）
- 规范表达：冷却下垫面、蒸发减弱、平流雾条件、上升流

## 常见图表与判读
- 洋流图：大陆西岸多寒流（一般规律，结合题图）
- 一句话模板：  
  - “受__寒流影响，下垫面冷却→蒸发弱、水汽少→沿岸偏干凉；暖湿气流过冷海面易成海雾。”

## 高频题型与答题框架（2–3条）
- 气候影响：寒流→降温→蒸发弱→减湿少雨→沿岸干旱
- 海雾题：暖湿气流+寒流冷海面→平流冷却→海雾

## 易错点与纠偏
- 易错：把“寒流=必然海雾”  
  - 纠偏：海雾还需要暖湿气流平流输送；仅有寒流不一定有雾
