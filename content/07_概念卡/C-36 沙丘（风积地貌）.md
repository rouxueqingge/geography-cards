# C-36 沙丘（风积地貌）

## 一句话定义
- 沙丘是干旱/半干旱地区在**沙源充足**且**风力搬运**条件下，因风速减弱或受障碍物影响而形成的**风积堆积地貌**。

## 核心机制（因果链）
- 沙源（松散砂物质）充足 → 风力起沙/搬运（跃移、悬移） → 遇到障碍或风速下降 → 砂粒沉降堆积 → 形成沙丘；强风持续 → 沙丘整体迁移（迎风侵蚀、背风滑塌）。

## 关键判据与特征
- 形态判据：**迎风坡缓、背风坡陡**；背风侧常见**滑塌面**。
- 动态判据：沙丘可迁移，迁移方向一般沿**主导风向**（结合题图判断）。
- 形成条件：干旱少雨（植被稀少）+风力强且稳定+沙源充足+地表粗糙度/障碍物。

## 常见图表与判读
- 照片/遥感：出现新月形、垄状等沙丘形态；背风侧阴影陡坎提示滑塌面。
- 判风向抓手：新月形沙丘两“角”多指向**下风向**（以题图标注为准）。
- 句式模板：
  - “沙源充足且风力搬运强，遇到__（障碍/风速减弱）→沉积堆积→形成沙丘；迎风坡缓背风坡陡。”

## 高频设问与答题要点
- **为什么形成沙丘？**：写“干旱少植被+沙源+主导风+风速减弱/障碍物”3–4点。
- **沙丘迁移方向/危害**：主导风向→沙丘推进→掩埋农田/道路/聚落；治理写“固沙+减风+减少沙源”。
- **比较题**：与雅丹对比：沙丘=风积；雅丹=风蚀（见D-13）。

## 易错点与纠偏
- 易错：把沙丘当成风蚀地貌。  
  - 纠偏：沙丘核心是“堆积”；风蚀地貌看“削低成沟槽脊”。
