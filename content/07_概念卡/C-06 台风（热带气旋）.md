# C-06 台风（热带气旋）

## 一句话定义
- 台风是发生在热带或副热带海洋上的强烈气旋性涡旋系统，以**强风、暴雨、风暴潮**为主要灾害表现。

## 核心机制（因果链）
- 暖海面蒸发强 → 水汽输送上升 → 凝结释放潜热 → 低压增强
- 气压梯度力 + 地转偏向力 → 形成气旋性环流 → 螺旋雨带发展
- 登陆后失去暖海供能 + 地表摩擦增大 → 强度迅速减弱
- 强风 + 短时强降水 + 海水增水 → 引发内涝、洪水、风暴潮

## 答题要点清单
- 关键词：热带海面、螺旋雨带、台风眼/眼墙、登陆、风暴潮
- 典型影响：暴雨引发洪涝/滑坡；强风倒伏损毁；沿海增水淹没
- 防灾表述：预警、停航停工、转移避险、加固设施、海堤与防潮闸

## 常见图表与判读
- 卫星云图：螺旋云系、中心相对清晰（眼）→台风特征
- 一句话模板：  
  - “系统源于热带海面，云系呈螺旋状并伴强风暴雨→判为台风（热带气旋）。”

## 高频题型与答题框架（2–3条）
- 成因题：暖海面+潜热释放→气旋增强→强风暴雨风暴潮
- 影响与措施：分别从“风、雨、潮”写3条影响，再对应3条措施

## 易错点与纠偏
- 易错：把所有气旋都叫台风  
  - 纠偏：台风属于强热带气旋；中纬度锋面气旋是温带气旋
