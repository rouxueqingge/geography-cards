# E-08 机制表层化型错误

> **错误本质**：只答"表层现象"不挖"内在机制"。原因分析类设问的评分点往往在**机制层**——停在现象层最多拿一半分。

## 典型真题错例

| 表层回答 | 内在机制 | 真题案例 |
|----------|----------|----------|
| 盐渍化=灌溉过量 | 核心机制是"**排水不畅**"——灌溉只是水源，排不出去才积盐 | [[Q-007_河套灌区]] |
| 砗磲记录台风 | 记录的是台风导致的**海洋环境变化**（水温降/营养盐增） | [[Q-048_砗磲古天气_11-12]] |
| 地形直接影响农业 | 地形通过改变**水热再分配**间接控制农业类型 | [[Q-050_橄榄梯田_16]] |
| 土壤含水量就是降水多少 | 收支平衡模型：输入（融雪）→输出（蒸发/蒸腾）→调节（植被） | [[Q-074_2025湖南冷龙岭]] |
| 袭夺是偶然事件 | 袭夺是流域地貌演化的**常态**——判断主动河与被动河 | [[Q-053_分水岭迁移_9-10]] |
| 有效辐射就是地面辐射 | 有效辐射=地面辐射**−大气逆辐射**，云多→逆辐射↑→有效辐射↓ | [[Q-016_辐射收支]] |

## 思维建模（源自阅卷评分细则）

**收支平衡模型**（一切"变化原因"类设问通用）：
```
输入项（+）→ 储存量变化 ← 输出项（−）
        ↑ 调节项（植被/人类活动）
```
2025湖南卷19(3)阅卷实录：趋势"先增后减"2分 + 增的原因"积雪消融"2分 + 减的原因"蒸发/植被吸收"2分——**每层机制单独给分**。

## 纠偏策略

1. **多问一层"为什么"**：写完初稿后对每个原因追问一次——能追出机制层
2. **收支建模**：变化类设问先画收支平衡式，再填具体过程
3. **间接影响意识**：地形/纬度等基础因子多为**间接**作用，中介是水热条件
