## 选择题专项参考

> 以下为「选择题解题技巧与常见错因」专项梳理，作为综合题十大错因之外的**选择题专项补充**，用于选择题限时训练与讲评。

### 一、六大解题技巧
| 技巧 | 适用情境 | 操作要点 |
|------|----------|----------|
| 优选法 | 选项明确、判断不难 | 直选法 / 比较优选法 / 猜测法（先选可能项再结合设问） |
| 排除法 | 选项复杂 | 排误（与题干无关/范围错）、排漏（缺正确项目）、排类（角度归类） |
| 代入法 | 计算类、关联图类 | 取特殊选项代入题干检验 |
| 因果法 | 由果溯因 / 由因推果 | 题干为果→溯因；题干为因→推果 |
| 正误法 | 知识扎实时 | 直接依正误选正确项 |
| 图表信息法 | 图表类 | 全面提取图中有用信息，挖掘地理事物与知识的联系 |

### 二、五类典型错误
| 类型 | 表现 | 规避要点 |
|------|------|----------|
| 对新概念分析不准确 | 题给新概念（术语/指标）未吃透即下结论 | 先拆解概念定义与材料解释，再迁移 |
| 无法提取隐性信息 | 只取显性文字，漏掉图例/注记/隐含条件 | 图文结合，圈画图例、注记、单位、时间 |
| 不明题干与选项的联系 | 选项本身对但不符合题意 | 以设问为锚，判选项是否应答了问题 |
| 忽略题组内联系 | 单题孤立看，漏掉题组材料/上题结论 | 把题组当整体，前题结论常为后题铺垫 |
| 无法灵活迁移知识 | 死记模板，遇新情境套不上 | 回归原理本质，建立"情境→原理"映射 |
